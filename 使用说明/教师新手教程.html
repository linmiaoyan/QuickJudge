1三分钟认识 QuickJudge

QuickJudge 是一套「拍照就能批」的作文与试卷智能批阅平台。学生写完的作文拍下来，系统自动认字、自动按你的要求批阅，并汇总成班级报告。

能力说明
🔍 智能识图手机拍照、扫描仪扫描或直接上传图片，自动把手写作文转成文字，并自动认出学生的 6 位学号
✍️ 智能批阅按你设定的批阅要求（评分、优点、问题、改进建议、修改意见）逐篇批阅，批阅标准由你写
📊 班级分析把整批作文汇总成一份班级报告：整体水平、共同优点、普遍问题、教学建议、好词好句
🧑‍🏫 人工阅卷打分板连续批阅，支持单评 / 双评 / 仲裁分差、按老师分配任务
📄 组卷与答题卡内置题库选题发布练习；一键生成试卷、答题卡、参考答案（Word / PDF），直接打印
🏫 班级中心按班级、按日期查看历次批阅报告，导出答题情况与班级报表
👨‍🎓 学生自查学生用自己的学号登录，可看到自己的历次批阅报告（原文 + 评语）

一句话流程：选题布置 → 打印发放 → 收卷拍照 → 上传识别批阅 → 看班级报告。

2登录与账号

2.1 从哪里打开

在浏览器（Chrome / Edge / Safari 均可）中打开下面任一地址：

场景地址
在运行服务的这台电脑上http://localhost:5001
同一局域网的其他电脑 / 手机http://运行服务的电脑IP:5001（IP 找管理员确认，一般是 10.x.x.x）

服务需要先启动。如果打开地址显示无法访问，多半是服务没开——请找管理员启动一次（macOS / Linux 执行 .venv/bin/python app.py，Windows 执行 .venv\Scripts\python app.py）。

2.2 三种角色

角色账号形式能用什么
学生6 位学号，如 250101登录后只看到「我的报告」，查看自己历次批阅记录

2.3 登录三步

  1. 打开网址看到蓝色标题和「请使用学号/工号登录」即可
  2. 输入账号与密码学生填 6 位学号；教师填工号或手机号
  3. 点「登录」登录成功进入首页；失败会在下方红字提示「账号或密码错误」

2.4 账号从哪来

对象获取方式初始密码

管理员系统内置账号，联系技术负责人—

教师注册需要邀请码。邀请码由管理员生成（管理员登录后 → 右上角「⚙️ 配置」→ 邀请码区域 → 「生成随机邀请码」）。一个邀请码可限定使用次数，请按需生成、用完即止。

拿到账号后请先改密码。系统交付时会预置演示用的教师与管理员账号，仅供试用与培训，请勿在真实教学中继续使用默认密码。

忘记密码怎么办？系统目前没有自助找回密码功能，需要联系管理员在后台重置（重置后密码为学号或指定值）。请提醒学生首次登录后牢记密码；如经常忘记，可统一由管理员重置为标准初始密码。

5分步操作详解

5.1 组卷布置 —— 选题并发布练习布置作业时用

用途：从平台内置题库挑一道作文题，配好素材和答题卡，作为一次「练习」发布给指定班级。

  1. 进入「组卷布置」左侧点一下即可
  2. 选择题库类型
    • 教材同步练习——按教材单元配套的写作任务
    • 应用文题库——通知、书信、演讲稿等
    • 读后续写题库——提供原文与两段首句
    • 自定义出题——自己写题目要求
  3. 筛选与预览用上方的筛选、搜索缩小范围，点开题目看详情
  4. 加入篮子挑中的题目点「加入篮子」，再点右下角「去布置」
  5. 勾选班级与学生在弹出的「选择班级与学生布置」窗口里勾选，点「确认布置」

页面顶部的配套按钮：

按钮作用
编辑作文素材维护可复用的写作素材（名句、范文片段等），支持「下载为 ZIP 备份」
编辑通用答题卡在平台内直接编辑答题卡版式，保存即生效，支持「下载为 HTML 备份」
预览 / 打印答题卡直接调起打印，不用先下载再传回
📄 从试卷 Word 生成答题卡把现成的试卷 Word 上传，自动识别题型生成配套答题卡
📋 按题型模板生成答题卡手动选择题型组合，快速套模板生成
➕ 添加素材新增一条自定义素材

5.2 阅卷管理 —— 导出答题卡与试卷发放前用

用途：把练习变成纸质材料发下去，并管理人工阅卷任务。

① 导出试卷与答题卡

  1. 进入「阅卷管理」默认停在「阅卷管理」子页签，可切到「我的阅卷」
  2. 找到对应的练习，点「导出试卷」
  3. 勾选导出内容
    • 试卷（Word）——题面，A4 排版
    • 答题卡（PDF）——学生作答用，带学号填写区
    • 参考答案（Word）——讲评用
  4. 点「确定」保存到本机再打印发放

② 一键导出数据

按钮导出什么
导出答题情况逐生的学号、批阅报告等内容，用于成绩录入与归档（若本批还没有批阅结果，导出会是空表，会有提示）
导出班级报告班级整体评价报告，可选导出格式

③ 创建人工阅卷任务（需要多位老师协同时用）

  1. 点「创建阅卷任务」弹出两步向导
  2. 第 1 步：选练习列表只显示近 1 个月、且包含主观题（问答题、整句批改、半句批改、句子默写、篇章默写、应用文、读后续写）的练习
  3. 第 2 步：阅卷设置
    • 逐题型设定批阅模式：机评 / 单评 / 双评
    • 选择单评或双评的老师
    • 填写「需要仲裁的分差」与仲裁老师——两位老师给分差异超过该值时会自动转仲裁
    • 选择分配规则：按老师数量平均分配，或按老师所带班级的提交人数分配
    • 选择阅卷时是否显示机评分数（正式考试建议选「否」，避免先入为主）
  4. 点「保存」至少有一个题型选了人工批阅（单评 / 双评）才能创建成功

「上传试卷（识码归类）」按钮用于把已有的试卷图片直接上传，系统按答题卡上的二维码自动归类到学生。若提示暂不可用，请走「文件管理 → 上传 → 归档班级 → 智能阅卷」这条常规路径。

5.3 文件管理 —— 上传与归档高频操作

用途：把纸质作文变成系统里的图片，并按班级归档。

先分清两种卷

类型特征后续怎么批
📷 标准卷用平台生成的答题卡，带二维码、规范的答题区域和学号填写区归档到班级后直接批阅；二维码自动归档功能即将上线，目前先用班级归档
📄 不标准卷平时的卷子、以往的试卷，没有二维码导入后需要在「智能阅卷」里用「🎯 识别区域选择」框选作文区域，再批阅

上传步骤

  1. 进入「文件管理」，先在左侧创建或选择班级输入班级名称点「创建」；已建过的直接点选。归档到哪个班级，报告就归到哪个班级
  2. 点「📷 标准卷」或「📄 不标准卷」会跳出说明与两个导入方式
  3. 选择导入方式
    • 扫描仪——连接扫描仪连续扫描（依赖 Windows 上的 NAPS2 工具；扫描进度显示为「已扫描 → 已识别 → 已上传」三步）
    • 本地图片上传——手机上拍好照片先传到电脑，再整批选择上传
  4. 在「🖼️ 图片文件」中勾选图片可点「✅ 全选」；勾选后会出现「🗑️ 删除选中」「🎯 识别区域选择」「📝 前往批阅」
  5. 点「📝 前往批阅」跳到智能阅卷也可以先「🎯 识别区域选择」框好区域再过去

必须做的事：让学生在作文纸最上方写清 6 位学号（如 250101）。系统会自动识别并归档到对应学生；识别不到时，可在「智能阅卷」里点「👤 设置学号」手动指定。学号必须是 6 位数字，否则无法归档。

拍照 / 扫描质量要求 —— 直接决定识别准确率

做到这几点，识别准确率能上一个台阶：

  • 光线均匀，不要有阴影和反光（避开台灯直射、窗边背光）
  • 纸张放正，四角完整，不要拍歪、不要缺角
  • 分辨率够高、字迹清晰，建议图片宽度 1600 像素以上
  • 一次一张，不要把多张叠在一起或把桌面杂物拍进去
  • 铅笔字、颜色过淡的字迹，请学生用黑笔重描或改深色笔书写
  • 涂改太多会影响识别，建议要求学生在原文上划一条横线后重写

5.4 智能阅卷 —— 一键识别并批阅核心步骤

用途：把图片变成「识别文本」和「批阅报告」。

  1. 在「文件管理」勾选要批阅的图片或从阅卷管理的「任务试卷」里勾选后点「前往批阅」，会自动带入
  2. 切换到「智能阅卷」上方会出现「📸 已选图片预览」，先确认选对了、图够清晰
  3. （不标准卷 / 手写卷）点「🎯 识别区域选择」在图上框出作文正文区域，避免把姓名栏、题目、页眉页脚一起识别进去
  4. （可选）点「✏️ 编辑批阅提示词」调整批阅要求见下方说明，一次设定长期生效
  5. 点「🚀 识别并批阅」出现进度提示。每篇约 30–60 秒，期间请勿关闭页面、勿重复点击
  6. 查看结果页面出现「📝 OCR 识别结果」和「📋 批阅结果」两块；结果页底部可点「📊 生成班级报告」，把本批学生汇总成班级分析

批阅提示词（决定批阅风格的关键）

编辑框里用 {essay_text} 作为作文占位符，系统会自动替换成学生作文内容。改动后点保存，长期生效，无需每篇重设。

默认模板要求输出：总体评分 / 优点分析 / 问题指出 / 改进建议 / 具体修改意见，并用中文回复。

如果想更贴合你的评分标准，可以改成这样：

请按高一英语作文评分标准批阅下面这篇作文，严格输出以下四部分：
1. 总分（满分 25 分）及分项分（内容 / 语言 / 结构，各占比请注明）
2. 优点 2 条，各附一个原文中的例子
3. 问题 2 条，逐条给出修改后的句子
4. 一句话总评（不超过 30 字）

作文内容：
{essay_text}

请用中文回复。

效率建议：一次勾选 5–10 篇最稳。批量很大时请分成几批跑——几十篇一起提交等待时间长，中途万一网络波动会更麻烦。

5.5 人工阅卷 —— 打分板需要复核或联考时用

  1. 「阅卷管理」→「人工阅卷」列出待批阅的试卷，点开进入打分板
  2. 用打分板快速给分
    • 「满分」「零分」一键给极端分
    • 「+0.5 分」微调，也可直接输入分数
    • 右侧可展开「试题答案」对照
  3. 点「保存并下一人 >」连续批阅不用反复返回列表
  4. 用「我的阅卷」跟踪进度可按「全部 / 待批阅 / 已完成」筛选；顶部「阅卷进度（按任务）」查看各任务完成情况

双评模式下，系统按创建任务时设定的分配规则自动派卷；两位老师给分差异超过设定阈值，会转给仲裁老师处理。

5.6 班级中心与我的报告 —— 看成果讲评 / 归档

  1. 「班级中心」列出所有班级每个班显示日期批次数量与学生人数
  2. 点「历次报告」按日期列出该班每次批阅，显示当次涉及的学生数；可查看当前班级学生名单
  3. 点「成绩报表」学号与分数联动展示，用于横向对比与成绩录入

班级中心里没有内容？多半是这两个原因：① 上传时没有选中班级，图片没归到任何班；② 学生的学号没被识别出来（不是 6 位数字，或没写在作文上方）。回「文件管理」检查归档，或在「智能阅卷」用「👤 设置学号」补上。

6学生端怎么用

学生使用非常简单。下面这段可以直接复制发给学生（微信群、班级公告都行）：

同学你好：

在浏览器打开 http://（老师提供的地址）:5001，用你的 6 位学号登录，密码默认也是你的学号。登录后点左侧「我的报告」，就能看到自己每一次作文的批阅报告——里面包含识别出的作文原文、评分和老师的评语。

写作文时请记得：把 6 位学号写在作文纸最上方显眼的位置，字迹写清楚，别写连笔，这样系统才能准确认出来。

7常见问题 FAQ

点了「识别并批阅」一直转圈，或者报错怎么办？

按顺序排查：

  • 确认已经勾选了图片（没勾选时按钮是灰的，或者会提示先去文件管理选图）
  • 确认运行服务的电脑能访问外网——识别与批阅由云端大模型完成，断网就一定会失败
  • 把这一次的数量减少到 5 张以内重试，排除单张图片过大或损坏
  • 仍不行就把操作时间、报错文字告诉技术负责人，他需要看服务窗口的日志
一篇要等多久？一次能批多少？

单篇约 30–60 秒（包含图片识别 + 生成批阅报告两步）。一次建议 5–10 篇，页面会有进度提示。批量很大的时候请分批提交，跑批期间不要关闭页面。

识别出来有错字、漏字怎么办？

手写连笔、涂改、光线不好是最常见的原因。可以这样改善：

  • 拍照时提高清晰度，避免阴影和反光（见 5.3 的质量要求）
  • 用「🎯 识别区域选择」只框作文正文部分，把姓名栏、题目、页眉页脚排除掉
  • 在批阅提示词里加一句约束，例如「看不清的字用 □ 占位，不要猜测」
  • 关键内容（分数、学号）以人工复核为准——机器结果是辅助，不是最终判定
同一篇作文，两次批阅分数不一样？

系统已经把批阅的随机性调得很低，但大模型仍可能有 ±1 分的浮动。建议：① 在提示词里写明明确的评分细则和分档标准；② 最终成绩以教师复核为准。如果是统一考试或重要测评，建议结合「人工阅卷」的实体打分板使用。

学号没识别出来，或者归到别人名下了？
  • 先确认学号是 6 位数字——非 6 位数字的学号系统无法自动归档
  • 提醒学生把学号写在作文纸最上方的显眼位置，字写清楚
  • 识别完成后，在「智能阅卷」点「👤 设置学号」手动指定正确的学生
  • 归错人的记录，可请技术负责人从班级中心的数据文件里修正
在 Mac 电脑上点扫描仪报错？

扫描仪功能依赖 Windows 上的 NAPS2 工具，在 macOS 上不可用（页面会提示初始化失败），这属正常现象。改用「本地图片上传」即可——用手机拍照后传到电脑再整批上传，批阅效果完全一样。另外服务启动时打印的一段扫描相关报错也可以忽略，不影响主功能。

数据存在哪里？会不会丢？

所有数据都保存在运行服务的这台电脑上（项目目录下的 data 文件夹：班级、学生名单、批阅结果、历史记录都在里面）。

请不要删除或移动 data 文件夹。建议每月把整个 data 目录复制一份到移动硬盘或网盘做备份；换电脑时也只需拷贝这个目录。

学生登录后看不到自己的报告？
  • 确认学生用的是 6 位学号登录，且账号里确实有这个学号
  • 确认这篇作文的学号被正确识别、并且图片已归档到班级——只有归到班级的记录才会出现在报告里
  • 让学生点一下「刷新」或重新登录一次
想让另一位老师也能用，怎么加账号？

请管理员登录 → 右上角「⚙️ 配置」→ 找到邀请码区域 → 点「生成随机邀请码」（可限定使用次数）→ 把邀请码给这位老师。对方在登录页点「教师注册」，填邀请码、账号（建议用手机号）和密码即可开通。

学生名单怎么一次性导进去？

管理员在「⚙️ 配置」里可以：① 点「从根目录 namelist.csv 导入」——需先把名单文件命名为 namelist.csv 放在项目根目录；② 点「上传 CSV」——直接上传自己的名单表（推荐，不用碰服务器文件）。

CSV 只有两列，第一行是表头，格式为：

学生姓名,登录账号
示例甲,250101
示例乙,250102

导入后学生的初始密码就是自己的登录账号（学号）。重复导入不会覆盖已存在账号的密码。

8使用规范与提醒

推荐做法

  • 每学期/每单元第一次使用时，先把班级建好、把学生名单导进去，后面所有操作都会顺很多
  • 让学生养成「作文纸上方写 6 位学号」的习惯，这一条能省掉八成的人工纠错
  • 批阅提示词一次调好，全学期复用；换文体（应用文、读后续写）时可另存一份说明让技术负责人切换
  • 每批控制在 5–10 篇，逐批批阅，边批边看结果，发现识别偏差及时调整拍照方式
  • 每月备份一次 data 目录

请注意

  • AI 批阅是辅助，不是最终判定。分数与评语请以教师复核为准，尤其是升学相关的重要测评
  • 批阅需要把学生作文图片传到云端大模型处理。请遵守学校的数据使用与隐私规定，不要把与教学无关的图片、含个人隐私的内容上传
  • 不要把服务地址和账号密码发到班级群里（学生端只需要学号登录入口）
  • 每个批阅周期结束后，及时清理不再需要的图片，避免磁盘占满
  • 学生如使用他人学号登录，会看到他人的报告——请务必强调账号使用规范

B名词解释

名词含义
标准卷用平台生成的答题卡印出来的卷子，带二维码、规范答题区和学号填写区
不标准卷平时或以往的卷子，没有平台二维码，需要手动框选识别区域
识别区域选择在图片上框出真正要识别的部分（作文正文），排除姓名栏、题目等干扰
批阅提示词告诉 AI「按什么标准、输出哪几部分」的模板，用 {essay_text} 代表作文正文
组卷布置从题库选题并发布给班级，形成一次「练习」
阅卷任务把一次练习的批阅工作分配给多位老师，可设单评 / 双评 / 仲裁
单评 / 双评一篇由 1 位老师打分，或由 2 位老师分别打分
仲裁分差双评时两位老师给分差超过这个值，就转给仲裁老师定分
班级中心存放各班级历次批阅报告与成绩报表的地方
机评分数AI 给出的分数（可与人工阅卷对照，或选择阅卷时不显示）
