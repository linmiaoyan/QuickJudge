# 扫描点部署（扫描仪旁边那台 Windows）

三台扫描仪同时用，处理中心只有一台。分工是这样：

```
  [扫描仪 A]──USB──[Windows A]┐
  [扫描仪 B]──USB──[Windows B]├─ 局域网 ──> [Linux 服务器] 批阅 / 入库 / 报告
  [扫描仪 C]──USB──[Windows C]┘              data/ 只在这里
```

扫描点那台电脑**不存任何数据**：扫出来的图逐页传上去，本地只留一份临时 png，
传完就删。所以那台机器坏了、重装系统，换个新电脑重装一遍就行，班级和记录一条都不会丢。

---

## 一、前提

| 项目 | 要求 | 为什么 |
|---|---|---|
| 系统 | Windows 10 / 11 | 只有 Windows 能跑 NAPS2 的 TWAIN 驱动 |
| Python | 3.8 以上，装的时候勾 **Add python.exe to PATH** | `install.cmd` 要调 `pythonw` 起代理 |
| 扫描仪驱动 | 厂商自带的 TWAIN 驱动 | NAPS2 本身不认设备，只调用驱动 |
| NAPS2 | 便携版或安装版都行 | 实际出图的是它 |
| 网络 | 能访问主机 `http://服务器IP:5001` | 传图、取学科/任务列表都要用 |

> 扫描点**不需要**装 Flask，也不需要 `pip install` 任何东西。
> `scan_point.py` 只用 Python 标准库，这是刻意的：学校机房常常没有外网，
> 多一个依赖就多一道装不上的坎。

---

## 二、第一次装（每台做一次，约 3 分钟）

**第 1 步｜在主机上建点**

主机浏览器打开 `http://服务器IP:5001/scanpoints` → 「新建扫描点」→ 起个能认出来的名字
（比如「一楼 3 号机」）→ 复制它给的链接。

**第 2 步｜在扫描点电脑上打开那个链接**

形如 `http://服务器IP:5001/join?t=xxxxxxxx`。页面会显示这台机器是哪个点，
点「下载安装包」。

> 链接里的 `t=` 就是这台机器的身份，**等于钥匙**。别发到群里，别写在纸上贴显示器。
> 泄露了就在主机上删掉这个点、重建一个，旧链接立刻失效。

**第 3 步｜解压，双击 `install.cmd`**

安装包里的东西：

| 文件 | 作用 |
|---|---|
| `scan_point.py` | 代理本体 |
| `config.json` | 主机地址 + 令牌，**已经填好**，不用改 |
| `install.cmd` | 注册开机自启 + 启动代理 + 打开页面 |
| `run_agent.cmd` | 平时手动启动用（开机自启失效时） |
| `README.txt` | 同这份说明的简版 |

`install.cmd` 会在「启动」文件夹里放一个 `QuickJudgeScanPoint.cmd`，所以以后开机
代理自己就起来了，不用人去点。

**第 4 步｜在打开的页面里选一次扫描仪**

页面顶部的「扫描仪」区域会自动探测 NAPS2 和已连接的设备，确认设备名、
进纸方式（feeder 自动进纸 / glass 平板）、分辨率（默认 300dpi 彩色）后保存。
这一步每台机器只做一次。

---

## 三、平时怎么用

1. 打开 `http://127.0.0.1:5101/`（桌面留个快捷方式最快）。
2. 选学科、任务、满分——这三项是**这台机器**的，和别的扫描点互不影响。
3. 把纸放进进纸器，点「开始扫描」。页面会显示「扫描中 → 上传 3/8 → 已建批」。
4. 扫完这批的进度会显示在主机后台，批阅也在主机上跑。

**同时扫多台会不会打架？** 不会。每台机器各自建批，批号和记录互不覆盖。
真正共用的是模型接口的并发额度（`LLM_MAX_CONCURRENCY`，默认 8），
三台一起扫十几份的时候会排队，属正常现象。

## 四、报错对照

页面上给的提示已经是中文，这里补一下"听到/看到这句时该做什么"：

| 提示 | 真实原因 | 怎么办 |
|---|---|---|
| 扫描仪没有连上或没就绪 | 设备没枚举到（`TWAIN error: NoDS`） | 查电源和 USB 线；关掉别的扫描软件。**这条要等约 90 秒才会出现**，不是卡住了 |
| 扫描仪连接被占满 | 上一次的 `NAPS2.Console` 没退干净 | 任务管理器结束 `NAPS2.Console.exe`，或拔插一次 USB |
| 扫描仪脱机 | 设备休眠 / 被别的程序独占 | 按一下机身电源键唤醒 |
| 没有进纸 | 纸没进到进纸器 | 放纸，两边导纸板贴住纸边 |
| 扫描超时 | 一叠太多页 | 分两次扫，每次 20 页以内更稳 |
| 上传失败，已重试 3 次 | 主机不可达 / 网络掉了 | 看主机 `systemctl status quickjudge`；网络恢复后重新点开始，**只需重传这一页** |

**关键设计**：一页一个请求。断网时不会把整批作废，重试仍失败就停在那一页，
不会把半批图混进库里。

## 五、几个容易踩的坑

1. **别在扫描点电脑上同时打开 NAPS2 图形界面**。TWAIN 驱动一次只让一个程序占设备，
   图形界面开着，代理这边就会报 `MaxConnections`。
2. **扫描点电脑的时钟要对**。令牌本身不过期，但主机判断"这个点是否在线"用的是
   30 分钟内有没有上报，时钟差太多会显示成离线。
3. **换电脑不用改主机配置**。把安装包在新机器上重装一遍即可；旧的那台删掉
   `QuickJudgeScanPoint.cmd` 和整个目录就干净了。
4. **`config.json` 里有令牌**。整个文件夹拷给别人，等于把这台机器的上传权限给出去。
   要转机器，用主机上新生成的链接重新下载安装包。
